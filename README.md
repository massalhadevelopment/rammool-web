# rammool.com

Built static files of the «رمّول» (Rammool) sign-up site, served by GitHub Pages at https://rammool.com.

- Do not edit files here by hand. The source is `web/` in the private app repo; build with `npm run build` there and replace everything here except `CNAME`, `.nojekyll` and this README.
- Every key in the bundle is a public client key (Supabase publishable key, RevenueCat Web Billing public key). No secrets belong in this repo.
